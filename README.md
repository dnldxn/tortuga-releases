# Tortuga — releases

Builds of **Tortuga**, a modern remake of *Sid Meier's Pirates!* (test builds; the source is private).

Download the latest build from [Releases](https://github.com/dnldxn/tortuga-releases/releases/latest):

| Platform | File |
|---|---|
| Windows | `Tortuga-0.N-windows.zip` |
| macOS | `Tortuga-0.N-macos.zip` |
| Linux (x86_64) | `Tortuga-0.N-linux.tar.gz` |
| Dedicated server (linux-arm64) | `tortuga-server-linux-arm64.tar.gz` (+ `.sha256`) |

The game updates itself: **Check for updates** in the main menu downloads and verifies the newer
pack, then restarts. The `.pck` files and `update.json` are for that updater.

Found a bug? [Open an issue](https://github.com/dnldxn/tortuga-releases/issues).
